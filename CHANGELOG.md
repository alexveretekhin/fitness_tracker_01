# Changelog

Все заметные изменения проекта. Новые записи сверху.

## Правки после этапа 4.2 (2026-11-02)

- Раскрытый день в истории: под названием упражнения слева превью анимации, справа подходы с оранжевой скобкой.
- Кнопка «Открыть на главной →» из истории убрана.

## Этап 4.2. История: календарь и дни с подходами (2026-10-30)

- В истории лента с огоньками и риска под ней: потянул или тапнул, и лента раскрывается в месяц с оранжевыми точками и счётчиком тренировок. Огоньки перелетают на свои дни и становятся точками.
- День в списке раскрывается вниз: упражнения, подходы и вес. Кнопка «Открыть на главной →».
- Лента на главной встаёт вокруг выбранного дня, если он далеко от сегодня.
- 4 теста на сетку месяца, ADR 0007.

## Правки после этапа 4.1 (2026-10-30)

- Упражнение убирается из дня крестиком × на его строке на главной. Если подходы уже записаны, приложение переспрашивает.
- Кнопка «Убрать упражнение» из карточки подходов убрана.
- Исправлено: если вкладка была открыта со вчера, упражнения записывались во вчерашний день. Теперь после полуночи приложение само переключается на новый «сегодня» (проверка при возврате на вкладку и раз в минуту), тесты в `useAppStore.test.ts`.

## Этап 4.1. Голосовой ввод подходов (2026-10-29)

- Кнопка 🎤 в карточке: сказал «60 кило 10 раз», и вес с повторами встали в поля.
- Разбор фраз цифрами и словами, 20 тестов на Vitest, тесты фронтенда в GitHub Actions.
- `pnpm dev:https` для проверки микрофона с телефона, ADR 0006.

## Этап 4. Тренировки на сервере, подходы по одному (2026-10-29)

- Подход = отдельная запись `WorkoutSet` (вес × повторы), миграция переносит старые данные.
- API: добавить, исправить, удалить подход; удалить все тренировки.
- Карточка упражнения: список подходов, поля с кнопками − / +, кнопка «+ подход» с прошлыми значениями.
- Дни, огоньки, история и аватар хранятся на сервере, а не в браузере.
- Экран «Нет связи с сервером», 14 тестов, ADR 0005.

## Этап 3. Скелет фронтенда (2026-10-24)

- Vite + React 19 + TypeScript + Tailwind v4, роутинг TanStack Router.
- Экраны: заставка, выбор аватара, главная с лентой недели и огоньками, группы мышц, упражнения, история, настройки.
- Полёт упражнения к «+» со счётчиком, карточка подходов (Motion).
- Каталог мышц и упражнений из API через TanStack Query и клиент, сгенерированный openapi-ts.
- Дни и подходы пока в localStorage, Biome для проверки кода, ADR 0004.

## Этап 2. Скелет бэкенда (2026-10-24)

- FastAPI + SQLModel + Alembic на uv, Python 3.13.
- Таблицы: пользователь, группы мышц, упражнения, связь упражнение↔мышцы, дни и упражнения дня.
- API: каталог, дни тренировок с подходами и огоньками, аватар.
- Каталог из 9 групп и 40 упражнений, seed-скрипт.
- 11 тестов, GitHub Actions для бэкенда, ADR 0003.
