# Правила проекта для Claude

- Автор проекта новичок. Каждое изменение объясняй простым языком, на русском.
- Один этап = одна ветка = один Pull Request. В конце этапа обнови `docs/stages/NN-*.md` по шаблону из `docs/stages/README.md` и добавь запись в `CHANGELOG.md`.
- Любое заметное решение (библиотека, формат, структура) оформляй как ADR в `docs/decisions/` по шаблону `0000-template.md`.
- Новый термин, который встретился впервые, добавляй в `docs/glossary.md`.
- Сообщения коммитов: Conventional Commits (`feat:`, `fix:`, `docs:`, `chore:`, `refactor:`, `test:`).
- Структура: бэкенд в `app/backend`, фронтенд в `app/frontend`, документация в `docs/`.
- Пользователь работает на Windows: команды в документации давай для PowerShell.
- Не клади в git файлы .blend/.fbx/.ztl и другие тяжёлые исходники (>50 МБ), только экспортированные ассеты.
- Секреты только в `.env` (он в .gitignore), пример значений в `.env.example`.
