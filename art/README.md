# Art

Готовые экспорты для приложения: анимации (WebP/WebM), модели (GLB), иконки (SVG).
Исходники .blend/.fbx/.ztl сюда не кладём (они игнорируются git), храним вне репозитория.

Правила для рендеров анимаций: 512x512, 24 кадра/с, 1-3 секунды, до 500 КБ, имена вида `workout-complete.webp`.
Демо упражнений: один риг и одна сцена с одинаковой камерой и светом, меняется только анимация.
