# Иконки

Все иконки в SVG с `fill="currentColor"`: цвет берётся из CSS (`color`), поэтому одна иконка работает и оранжевой в меню, и серой в неактивном состоянии.

| Файл           | Где используется                                                          | Откуда                          |
| -------------- | ------------------------------------------------------------------------- | ------------------------------- |
| `flame.svg`    | Огонёк стрика в ленте недели (красный = был день тренировки, серый = нет) | Обведён из `fill_-embers.png`   |
| `history.svg`  | Кнопка «История» в нижнем меню                                            | Обведён из `History.png`        |
| `folder.svg`   | Вариант иконки «История» как в макете (папка)                             | Нарисован вручную               |
| `plus.svg`     | Кнопка «Добавить упражнения»                                              | Обведён из `plus.png`           |
| `settings.svg` | Кнопка «Настройки»                                                        | Обведён из `Settings.png`       |
| `play.svg`     | Кнопка демо упражнения                                                    | Обведён из `2936278-middle.png` |
| `search.svg`   | Поле поиска                                                               | Нарисован вручную               |

PNG из Figma переведены в векторы скриптом на potrace (контур по прозрачности). Это временные иконки для MVP, финальные автор нарисует сам.
