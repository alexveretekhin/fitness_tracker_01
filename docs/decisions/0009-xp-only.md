# 0009. Пока только опыт: без серии недель и заморозки

- Дата: 2026-11-04
- Статус: принято (заменяет часть решения [0008](0008-weekly-streak-xp.md) про серию и заморозку)

## Контекст

На этапе 5 сделали недельную серию (неделя засчитана при 3 тренировках), заморозку недели в Настройках и XP с уровнями. Автор попользовался и решил: серию и заморозку пока убрать, оставить только опыт.

## Решение

- Убираем серию недель: огонёк «N нед.» и точки недели ●●○ на главной, строку «Серия» на странице аватара.
- Убираем заморозку: пункт в Настройках, адреса `POST`/`DELETE /api/me/freeze`, таблицу `weekfreeze` (миграция `22ffa2f7a822` её удаляет).
- Оставляем XP и уровни без изменений: 50 XP за день с тренировкой, уровень 2 с 2000 XP, уровень 3 с 5000 XP.
- `GET /api/me/progress` больше не принимает `?today=`: XP не зависит от того, какая сегодня неделя.
- Огоньки в календаре остаются: это отметка «в этот день была тренировка», а не серия.

## Альтернативы

- **Спрятать серию только в интерфейсе, а код оставить.** Мёртвый код путает, особенно новичка. Если серия вернётся, её легко достать из истории git (PR #14) и ADR 0008.

## Последствия

- В базе для геймификации снова ничего не хранится, всё считается из подходов.
- После `git pull` нужно выполнить `uv run alembic upgrade head`, чтобы удалить таблицу `weekfreeze`. Старые заморозки пропадут, это нормально.
- Если серия понадобится снова, правила можно взять из ADR 0008.
