# 0016. Вход без регистрации: гостевой аккаунт на сервере

- Дата: 2026-11-13
- Статус: принято

## Контекст

Автор хочет, чтобы можно было начать без регистрации. Все данные у нас уже на сервере и привязаны к пользователю по токену (ADR 0014).

## Решение

- `POST /api/auth/guest` создаёт пользователя с `is_guest = true` без почты и отдаёт обычный JWT. Весь остальной код работает с гостем как с любым пользователем.
- Если гость регистрируется (почта+пароль или Google на новую почту), сервер не создаёт новый аккаунт, а дописывает почту гостю и снимает флаг. Тренировки, XP и аватар сохраняются.
- Старый пользователь по умолчанию (без почты и не гость) по-прежнему закрыт.

## Альтернативы

- **Хранить гостя в localStorage браузера, а при регистрации переносить на сервер.** Пришлось бы держать второй вариант всех экранов и логику переноса. Отказались.
- **Анонимные аккаунты Firebase.** Чужой сервис ради одной функции.

## Последствия

- Гость теряет данные, если потерял токен (очистка браузера, выход, другое устройство). Предупреждаем при выходе и предлагаем создать аккаунт в Настройках и профиле.
- В базе копятся брошенные гости. Позже можно чистить пустых старше 30 дней.
