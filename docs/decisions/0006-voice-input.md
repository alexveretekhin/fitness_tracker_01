# 0006. Голосовой ввод через распознавание речи в браузере

- Дата: 2026-10-29
- Статус: принято

## Контекст

В зале неудобно вбивать вес пальцем. Автор предложил говорить вес голосом или фотографировать гантель, чтобы ИИ сам записал число. Решили начать с голоса, фото отложили.

## Решение

- **Web Speech API** прямо в браузере, язык `ru-RU`. Бэкенд не участвует.
- **Свой разбор фразы** (`parseSet.ts`): числа цифрами и словами, «кг», «раз», «повторов», «на», «с половиной», «свой вес». Покрыт тестами на Vitest.
- **Голос только заполняет поля**, подход записывает человек кнопкой «+ подход».
- **Для телефона в разработке** нужен https: `pnpm dev:https` с самоподписанным сертификатом (`@vitejs/plugin-basic-ssl`).

## Альтернативы

- **Записывать звук и отправлять на бэкенд в Whisper или LLM.** Понимает любые фразы и работает в Firefox, но нужен платный ключ API и больше кода. Вернёмся, если браузерного распознавания не хватит.
- **Разбирать фразу через LLM** («жим 60 на 10» → JSON). Гибко, но платно и с задержкой. Свой разбор бесплатный и мгновенный.
- **Фото → ИИ с распознаванием картинок.** Отложено автором. Понадобится ключ API на бэкенде и эндпоинт для загрузки фото.

## Последствия

- В Firefox голосового ввода нет, кнопка скрыта.
- Нужен интернет: распознаёт сервер Google или Apple.
- Новые фразы добавляются в `parseSet.ts` вместе с тестом.
