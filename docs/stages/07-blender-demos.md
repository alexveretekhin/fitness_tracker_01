# Этап 7. Демо упражнений из Blender

## Цель

Анимацию упражнения, сделанную в Blender, одной командой превратить в лёгкое видео, которое сразу играет по кнопке Play в приложении.

## Что сделали

- Скрипт рендера [art/blender/render_demos.py](../../art/blender/render_demos.py): берёт сцену, по очереди ставит на персонажа анимацию каждого упражнения, рендерит и собирает `<id>.mp4` и `<id>.webm` в `app/frontend/public/animations/exercises/`. Пишет размер каждого файла и предупреждает, если больше 500 КБ.
- Обёртка для PowerShell [art/blender/render-demos.ps1](../../art/blender/render-demos.ps1): сама находит `blender.exe`.
- Компонент [ExerciseDemo](../../app/frontend/src/components/ExerciseDemo.tsx) теперь сам ищет демо по id упражнения ([lib/demo.ts](../../app/frontend/src/lib/demo.ts)): сначала WebM, потом MP4. Если файла нет, показывает «анимация скоро». 2 теста в `demo.test.ts`.
- Пробные рендеры (`-Preview`) идут в `art/demos-preview/`, эта папка в `.gitignore`.
- Решение: [ADR 0017](../decisions/0017-blender-demo-pipeline.md).

## Новые технологии

- **Action** — в Blender это «клип» анимации: набор ключей для рига. У одного персонажа может быть много Action, а играет тот, что назначен.
- **Фоновый режим Blender** (`--background`) — Blender запускается без окна, выполняет Python-скрипт и закрывается. Так рендерят пачкой.
- **ffmpeg** — программа для видео: склеивает картинки в ролик и сжимает. H.264 (MP4) открывается везде, VP9 (WebM) даёт файл меньше.
- **CRF** — «качество» при сжатии: больше число — меньше файл и хуже картинка. У нас 26 для MP4 и 38 для WebM.

## Как подготовить сцену

Делаем отдельный файл, например `D:\fitness_tracker_01\demos.blend` (вне репозитория, в git не попадает).

1. **Персонаж и риг.** Один Armature, на нём toon-материалы. Если в сцене несколько Armature, укажи нужный: `-Rig Имя`.
2. **Камера и свет** общие, кадр квадратный: скрипт сам ставит 512×512.
3. **Фон** — цвет приложения `#1A1A1A` (World → Color). Чтобы цвет не «уплыл», в Render Properties → Color Management поставь View Transform **Standard** (не AgX/Filmic).
4. **Частота 24 кадра/с** (Output Properties → Frame Rate).
5. **Анимация упражнения = Action с именем id упражнения.** Имена смотри в [catalog.py](../../app/backend/app/catalog.py): `push-ups`, `squat`, `barbell-bench`... В Action Editor (Dope Sheet → Action Editor) создай новый Action и переименуй.
6. **Нажми щит (Fake User)** рядом с именем Action. Иначе Blender удалит неиспользуемый Action при сохранении, и анимация пропадёт.
7. **Петля:** последний ключ = копия первого (Ctrl+C / Ctrl+V позы). Скрипт этот последний кадр не рендерит, поэтому стык не дёргается. Длина 1–3 секунды (24–72 кадра).
8. **Снаряды** (штанга, скамья, гантели) клади в коллекции с именами вида `props:barbell-bench,dumbbell-bench`. Коллекция видна только в этих упражнениях, в остальных скрыта. Гантель в руке крепи к кости констрейнтом Child Of.

## Как запустить и проверить

Один раз поставь ffmpeg и перезапусти терминал:

```powershell
winget install Gyan.FFmpeg
ffmpeg -version
```

Из папки репозитория:

```powershell
cd D:\fitness_tracker_01\fitness_tracker

# 1. Какие Action нашлись: + есть анимация, - нет, ? имя ни к чему не подошло
.\art\blender\render-demos.ps1 -Blend D:\fitness_tracker_01\demos.blend -List

# 2. Быстрая проба одного упражнения (маленькая, в art\demos-preview)
.\art\blender\render-demos.ps1 -Blend D:\fitness_tracker_01\demos.blend -Only push-ups -Preview

# 3. Чистовой рендер всех готовых упражнений прямо в приложение
.\art\blender\render-demos.ps1 -Blend D:\fitness_tracker_01\demos.blend
```

Если PowerShell пишет «выполнение сценариев отключено», один раз выполни:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

Потом запусти приложение (`pnpm dev` в `app\frontend`), открой упражнение и нажми Play: играет новое демо. Готовые файлы закоммить: `git add app/frontend/public/animations/exercises`.

## На что обратить внимание

- **Сцену скрипт не сохраняет.** Размер кадра и выбранный Action меняются только на время рендера, твой .blend остаётся как был.
- **Имя Action должно совпасть с id буква в букву**, с дефисами и маленькими буквами. Ошибся — `-List` покажет его со знаком `?`.
- **NLA-дорожки** на риге на время рендера выключаются, иначе они смешаются с Action.
- **Рендер долгий**: 48 кадров EEVEE — около минуты, все 40 упражнений — заметно дольше. Сначала пробуй `-Preview`.
- **Файл больше 500 КБ** — сократи анимацию или упрости сцену (мелкий шум и частицы плохо сжимаются).
- **Браузер кэширует видео.** Перерендерил, а видишь старое — обнови страницу с Ctrl+F5.
- Скрипт проверен на кодировании и чтении каталога, но в Blender у автора запускается впервые: если упадёт, пришли текст ошибки из терминала.
