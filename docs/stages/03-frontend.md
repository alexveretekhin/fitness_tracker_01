# Этап 3. Скелет фронтенда

## Цель

Приложение открывается в браузере, все экраны из концепта кликаются, а каталог мышц и упражнений приходит с бэкенда из этапа 2.

## Что сделали

- Проект на Vite + React + TypeScript: [package.json](../../app/frontend/package.json), [vite.config.ts](../../app/frontend/vite.config.ts).
- Экраны в [src/screens](../../app/frontend/src/screens): заставка с черепом, выбор аватара, главная с лентой недели, группы мышц, упражнения группы, история, настройки.
- Карта экранов (адреса) в [router.tsx](../../app/frontend/src/router.tsx).
- Компоненты в [src/components](../../app/frontend/src/components): нижнее меню, лента недели с огоньками, полёт упражнения к «+», карточка подходов, иконки, строки списка.
- Связь с бэкендом в [src/api](../../app/frontend/src/api). Группы мышц, упражнения и поиск берутся из API.
- Клиент API сгенерирован по схеме бэкенда: [openapi-ts.config.ts](../../app/frontend/openapi-ts.config.ts), схема в [openapi.json](../../app/frontend/openapi.json).
- В бэкенде: короткие имена операций в [main.py](../../app/backend/app/main.py) и скрипт [export_openapi.py](../../app/backend/app/export_openapi.py), который сохраняет схему API в файл.
- Проверка кода Biome: [biome.json](../../app/frontend/biome.json). На каждый PR GitHub запускает Biome и сборку: [.github/workflows/frontend.yml](../../.github/workflows/frontend.yml).
- Решение о связи с API: [ADR 0004](../decisions/0004-frontend-api.md).

**Пока не на бэкенде:** выбранные упражнения дня, подходы и аватар хранятся в браузере (localStorage). На сервер они переедут на этапе 4.

## Новые технологии

| Что | Простыми словами |
| --- | --- |
| Vite | Сервер разработки и сборщик. Сохранил файл, и страница обновилась за долю секунды |
| React | Библиотека интерфейсов: экран собирается из компонентов, функций, которые возвращают разметку |
| TypeScript | JavaScript с типами. Ошибка «тут строка, а нужно число» видна ещё в редакторе |
| Tailwind CSS | Стили классами прямо в разметке: `bg-accent rounded-row`. Цвета берутся из наших токенов в `theme.css` |
| TanStack Router | Отвечает, какой экран показать по адресу (`/home`, `/muscles/chest`) |
| TanStack Query | Загружает данные с сервера и кэширует их: вернулся на экран, а список уже есть |
| openapi-ts | Читает схему API бэкенда и пишет готовые функции запросов и типы. Руками запросы не пишем |
| Zustand | Хранилище состояния приложения: выбранный день, аватар, упражнения дня |
| Motion | Анимации: полёт упражнения, выезд карточки, огонёк |
| Biome | Линтер и форматтер для TypeScript и CSS (как Ruff для Python) |
| Прокси Vite | Vite пересылает запросы `/api/...` на бэкенд, поэтому фронт и бэк выглядят для браузера одним сайтом |

## Как запустить и проверить

Нужны **два** окна терминала: в одном бэкенд, в другом фронтенд.

Окно 1, бэкенд (если ещё не запущен):

```powershell
cd D:\fitness_tracker_01\fitness_tracker\app\backend
uv run fastapi dev
```

Окно 2, фронтенд:

```powershell
cd D:\fitness_tracker_01\fitness_tracker\app\frontend
pnpm install
pnpm dev
```

Открой http://localhost:5173. Пройди путь: заставка → аватар → «Add Exercises» → Chest → тапни пару упражнений (они улетают в «+») → «+» → тапни упражнение → впиши вес и подходы → «Сохранить». Огонёк сегодняшнего дня загорится.

Проверка кода:

```powershell
pnpm lint    # Biome
pnpm build   # проверка типов TypeScript и сборка
```

С телефона: `pnpm dev` пишет адрес вида `Network: http://192.168.x.x:5173`. Открой его на телефоне в той же Wi-Fi сети.

## На что обратить внимание

- **«Нет связи с сервером»** на экране мышц значит, что бэкенд не запущен. Запусти его в отдельном окне.
- **Поменял API на бэкенде → обнови клиент:** `pnpm api`. Команда сохранит схему в `openapi.json` и перегенерирует `src/api/generated`. Если что-то сломалось, `pnpm build` покажет где.
- **`src/api/generated` руками не правим**, при следующей генерации всё перезапишется.
- **Данные дня пока в браузере.** Другой браузер или режим инкогнито покажет пустой день. Настройки → Reset data очищает всё.
- **Иконки SVG исключены из Biome:** они декоративные (`aria-hidden`), правило про `<title>` к ним не относится.
- **shadcn/ui и Vitest** из плана стека пока не понадобились. Добавим, когда будут нужны.
- **`pnpm` или `uv` «not recognized».** Терминал VS Code не видит новые программы, пока VS Code не перезапущен целиком (File → Exit). Быстрое решение для текущего окна: `$env:Path = "$env:USERPROFILE\.local\bin;$env:APPDATA\npm;$env:Path"`. Если pnpm нет и там, узнай его папку командой `npm config get prefix`.
- **С телефона «This site can't be reached».** Мешают VPN на компьютере (у нас AmneziaVPN) или брандмауэр Windows. Выключи VPN или включи в нём доступ к локальной сети. Сеть Windows должна быть частной: `Get-NetConnectionProfile | Set-NetConnectionProfile -NetworkCategory Private` в PowerShell от администратора.
