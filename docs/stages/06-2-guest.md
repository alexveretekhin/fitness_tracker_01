# Этап 6.2. Вход без регистрации (гость)

## Цель

Можно начать тренироваться в один тап, без почты и пароля. Позже гость создаёт аккаунт, и все его тренировки, XP и аватар переходят в этот аккаунт.

## Что сделали

- **Бэкенд:**
  - у пользователя флаг `is_guest` ([models.py](../../app/backend/app/models.py)), миграция `0d9216028e31`;
  - `POST /api/auth/guest` в [api/auth.py](../../app/backend/app/api/auth.py): создаёт пустой гостевой аккаунт и сразу отдаёт токен;
  - регистрация и вход через Google, если их вызвал гость, не создают новый аккаунт, а превращают гостя в обычный: почта и пароль добавляются, тренировки остаются;
  - `/api/me` отдаёт `is_guest`;
  - 4 новых теста в [test_auth.py](../../app/backend/tests/test_auth.py).
- **Фронтенд:**
  - на [экране входа](../../app/frontend/src/screens/Login.tsx) внизу «Без регистрации» → выбор аватара → главная;
  - Настройки: под именем «гость: тренировки только здесь» и пункт «Создать аккаунт»;
  - профиль: вместо почты кнопка «Создать аккаунт»;
  - гость открывает экран входа сразу на «Регистрации» с подсказкой «Создай аккаунт, и твои тренировки сохранятся в нём», внизу «Назад»;
  - при выходе гостя спрашиваем: «Ты гость: после выхода тренировки пропадут. Выйти?».
- Решение: [ADR 0016](../decisions/0016-guest-login.md).

## Новые технологии

Новых библиотек нет. Гость — это обычный пользователь в базе, только без почты. Его «ключ» — токен в браузере, как и у всех.

## Как запустить и проверить

После `git pull` обнови базу:

```powershell
cd D:\fitness_tracker_01\fitness_tracker\app\backend
uv run alembic upgrade head
uv run fastapi dev
```

Во втором окне:

```powershell
cd D:\fitness_tracker_01\fitness_tracker\app\frontend
pnpm dev
```

1. Выйди, если был внутри. Внизу экрана входа нажми «Без регистрации».
2. Выбери аватар, добавь упражнение и подход.
3. Настройки → «Создать аккаунт» → почта и пароль.
4. Ты на главной, тренировка на месте, в Настройках уже твоя почта.

## На что обратить внимание

- **Гость живёт в одном браузере.** Токен лежит в localStorage. Очистил данные сайта, вышел или открыл приложение на другом устройстве — гостевой аккаунт не найти, тренировки потеряны. Поэтому и напоминаем создать аккаунт.
- Если гость на экране входа выберет «Вход» в уже существующий аккаунт, он перейдёт в тот аккаунт, а тренировки гостя останутся в брошенном гостевом.
- Через Google на уже зарегистрированную почту гость тоже попадает в существующий аккаунт без своих тренировок.
- Брошенные гостевые аккаунты копятся в базе. Когда будет сервер (этап 8), можно раз в месяц удалять пустых гостей старше 30 дней.
