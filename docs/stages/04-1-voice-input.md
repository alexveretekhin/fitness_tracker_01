# Этап 4.1. Голосовой ввод подходов

## Цель

В карточке упражнения можно нажать 🎤 и сказать «60 кило 10 раз», и вес с повторами сами встанут в поля.

## Что сделали

- **Кнопка 🎤** в карточке подхода: [VoiceInput.tsx](../../app/frontend/src/components/VoiceInput.tsx). Нажал, сказал, проверил числа и нажал «+ подход». Сам подход голосом не записывается, чтобы ошибка распознавания не попала в историю.
- **Распознавание речи** в браузере: [useSpeech.ts](../../app/frontend/src/lib/useSpeech.ts). Язык русский, ошибки (нет микрофона, нет доступа, тишина) показываются текстом под кнопкой.
- **Разбор фразы** в вес и повторы: [parseSet.ts](../../app/frontend/src/lib/parseSet.ts). Понимает и цифры, и слова:
  - «60 кг на 10», «60x10»;
  - «шестьдесят два с половиной кило восемь раз»;
  - «10 раз по 60»;
  - «свой вес 15 повторов»;
  - «десять раз» (меняются только повторы).
- **Тесты** на разбор фраз (20 штук): [parseSet.test.ts](../../app/frontend/src/lib/parseSet.test.ts). Это первые тесты фронтенда, на Vitest. GitHub теперь запускает их на каждый PR.
- **`pnpm dev:https`**: сервер разработки по https, чтобы микрофон работал и на телефоне ([vite.config.ts](../../app/frontend/vite.config.ts)).
- **Иконка микрофона** [mic.svg](../../app/frontend/src/assets/icons/mic.svg).
- Решение и альтернативы: [ADR 0006](../decisions/0006-voice-input.md). Ввод по фото пока отложен.

## Новые технологии

| Что | Простыми словами |
| --- | --- |
| Web Speech API | Встроенное в браузер распознавание речи. Chrome и Safari отправляют звук на свои серверы и возвращают текст. Бесплатно, но нужен интернет |
| Безопасный контекст | Браузер даёт микрофон и камеру только на страницах `https://` или `http://localhost`. По `http://192.168...` нельзя |
| Самоподписанный сертификат | «Паспорт» для https, который сделали мы сами, а не центр сертификации. Шифрует так же, но браузер его не знает и предупреждает |
| Vitest | Тесты для TypeScript, родственник pytest. Работает на том же Vite |

## Как запустить и проверить

На компьютере всё работает как обычно, `localhost` браузер считает безопасным:

```powershell
cd D:\fitness_tracker_01\fitness_tracker\app\frontend
pnpm install
pnpm dev
```

Открой карточку упражнения и нажми 🎤. Браузер спросит разрешение на микрофон: разреши.

**С телефона** запусти фронтенд по https:

```powershell
pnpm dev:https
```

На телефоне открой `https://192.168.1.11:5173` (именно **https**). Браузер предупредит «Подключение не защищено»: нажми «Дополнительно» → «Перейти на сайт». Это наш самоподписанный сертификат, в домашней сети так можно. VPN на компьютере должен быть выключен.

Тесты:

```powershell
pnpm test
```

## На что обратить внимание

- **Firefox не умеет распознавать речь**, там кнопки 🎤 просто нет. Работает в Chrome (компьютер и Android) и Safari (iPhone, Mac).
- **Нужен интернет**: распознаёт не наш сервер, а сервер Google или Apple.
- **Одна фраза = один подход.** «Три подхода по 10» поймётся как 10 повторов, а подходы добавляй кнопкой.
- **Число без подписи** («80») считается весом. Если сказать «60 на 10», первое число уйдёт в вес, второе в повторы.
- **Предупреждение про сертификат** на телефоне нормально для `pnpm dev:https`. После деплоя (этап 8) будет настоящий сертификат и предупреждение пропадёт.
- **Распознавание иногда ошибается.** Поэтому числа только подставляются в поля, а записываешь ты сам.
