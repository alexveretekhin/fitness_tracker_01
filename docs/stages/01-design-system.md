# Этап 1. Дизайн-система из Figma

## Цель

Цвета, шрифт, иконки и картинки из макета лежат в репозитории в форме, готовой для кода, и их можно посмотреть на одной странице.

## Что сделали

- Сняли цвета с экспорта макета и записали их токенами в [theme.css](../../app/frontend/src/styles/theme.css).
- Перевели PNG-иконки в SVG: [app/frontend/src/assets/icons](../../app/frontend/src/assets/icons). Иконки поиска и папки нарисовали вручную.
- Сжали картинки в WebP и демо отжиманий в MP4/WebP: [app/frontend/public](../../app/frontend/public).
- Описали дизайн-систему: [docs/design/README.md](../design/README.md).
- Собрали витрину [showcase.html](../design/showcase.html): цвета, шрифт, иконки, три экрана. На ней уже работают полёт упражнения на главную и карточка подходов.
- Решение о форматах записали в [ADR 0002](../decisions/0002-assets-formats.md).
- Поправили подписи из макета: BICEPC → Biceps, GASTROCNEMIUSES → Calves.

## Новые технологии

| Что | Простыми словами |
| --- | --- |
| Дизайн-токены | Именованные значения дизайна (`accent = #ff3300`). В коде пишем имя, а не цвет, и меняем цвет в одном месте |
| Tailwind `@theme` | Блок в CSS, из которого Tailwind v4 сам делает классы: `--color-accent` → `bg-accent`, `text-accent` |
| SVG + `currentColor` | Векторная иконка, которая берёт цвет текста вокруг. Одна иконка, любой цвет, чёткая на любом экране |
| potrace | Программа, которая обводит картинку и превращает её в вектор |
| WebP, MP4 | Современные форматы: WebP для картинок, MP4/WebM для анимаций. В разы легче PNG и GIF |
| `prefers-reduced-motion` | Настройка системы «уменьшить движение». Уважаем её и выключаем анимации |

## На что обратить внимание

- **Шрифт угадан по картинке.** Проверь в Figma, как он называется. Если не Source Code Pro, поменяй `--font-mono` в `theme.css`.
- **Вес файлов.** GIF отжиманий весил 1,7 МБ, тот же ролик в MP4 весит 72 КБ. На телефоне в зале это разница между «сразу» и «грузится». Для демо упражнений будем использовать MP4/WebM.
- **Чужие картинки.** Черепа и скульпт девушки, похоже, из интернета. Для MVP нормально, для публикации нужны свои.
- **Витрина не приложение.** Она на чистом HTML/CSS/JS, чтобы открываться без установки. В приложении то же самое будет на React (этапы 3–4).
