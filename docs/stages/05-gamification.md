# Этап 5. Геймификация: недельная серия, XP, уровни

## Цель

Приложение мотивирует тренироваться: видно серию недель, очки опыта и уровень, а за тренировку прилетает награда. Этим этапом закрывается MVP.

## Что сделали

- **Правила** ([ADR 0008](../decisions/0008-weekly-streak-xp.md)):
  - тренировка = день хотя бы с одним подходом;
  - неделя (пн–вс) засчитана при 3 тренировках и больше, серия = сколько таких недель подряд;
  - 50 XP за день с тренировкой; уровень 2 с 2000 XP, уровень 3 с 5000 XP;
  - заморозка: 1 неделя в месяц не рвёт серию.
- **Бэкенд:**
  - расчёт в [progress.py](../../app/backend/app/progress.py), все числа в начале файла;
  - адреса `GET /api/me/progress` и `POST`/`DELETE /api/me/freeze` в [api/progress.py](../../app/backend/app/api/progress.py);
  - таблица `weekfreeze` и миграция `2ee644e22423`;
  - «Reset data» теперь удаляет и заморозки;
  - 11 тестов в [test_progress.py](../../app/backend/tests/test_progress.py).
- **Главная:** под календарём [XpBar.tsx](../../app/frontend/src/components/XpBar.tsx): огонёк и «N нед.», точки этой недели ●●○, справа «ур. 1 · 650/2000», ниже тонкая полоска. После первого подхода за день полоска доливается и всплывает «+50 XP».
- **Страница аватара** `/me` ([Profile.tsx](../../app/frontend/src/screens/Profile.tsx)): аватар в кольце XP ([AvatarRing.tsx](../../app/frontend/src/components/AvatarRing.tsx)), уровень, XP до следующего, серия, кнопка «Сменить аватар». Тап по аватару выдвигает снизу все уровни, закрытые тёмные с замочком и порогом XP.
- **Настройки:** аватар с маленьким кольцом ведёт на `/me`, пункт «Заморозить эту неделю» с остатком заморозок и кнопкой «отменить».

## Новые технологии

| Что | Простыми словами |
| --- | --- |
| Расчёт на лету | XP и серию не храним, а каждый раз считаем из подходов. Поменял правило, и всё пересчиталось само |
| `strokeDasharray` / `strokeDashoffset` | Свойства SVG-обводки: рисуем окружность пунктиром из одного штриха и сдвигаем его. Так получается кольцо прогресса |
| Параметр `today` в запросе | Фронтенд сам говорит, какое у пользователя сегодня число, потому что сервер может стоять в другом часовом поясе |

## Как запустить и проверить

После `git pull` обязательно обнови базу, появилась новая таблица:

```powershell
cd D:\fitness_tracker_01\fitness_tracker\app\backend
uv run alembic upgrade head
uv run fastapi dev
```

Во втором окне:

```powershell
cd D:\fitness_tracker_01\fitness_tracker\app\frontend
pnpm dev
```

1. На главной под календарём появились серия и полоска XP.
2. Запиши подход в упражнение сегодняшнего дня: полоска дольётся, всплывёт «+50 XP».
3. Настройки → Avatar: страница с кольцом. Тап по аватару покажет закрытые уровни.
4. Настройки → «Заморозить эту неделю», потом «отменить».

Тесты: `uv run pytest` в бэкенде, `pnpm test` во фронтенде.

## На что обратить внимание

- **Без `alembic upgrade head` бэкенд упадёт** на `/api/me/progress`: таблицы `weekfreeze` ещё нет.
- **XP даётся за день, а не за подход.** Второй подход в тот же день XP не добавляет.
- **Удалил все подходы дня, и XP за него пропадёт**, серия тоже может уменьшиться. Это честный пересчёт.
- **Заморозить можно только текущую неделю** и только если она ещё не засчитана. Прошедшую неделю задним числом не заморозить.
- **Аватары 2 и 3 уровня пока силуэты** текущего аватара. Когда будут арты, их надо положить в `public/images/avatars` и подключить в `AvatarRing.tsx`.
