# Дизайн-система

Всё, из чего собирается интерфейс: цвета, шрифт, иконки, картинки и правила поведения. Источник правды для кода: [theme.css](../../app/frontend/src/styles/theme.css). Посмотреть вживую: открой [showcase.html](showcase.html) двойным кликом.

## Цвета

Сняты пипеткой с экспорта макета `Context_for_Cloude/Figma_export/fitness_tracker.png`.

| Токен | Цвет | Где |
| --- | --- | --- |
| `bg` | `#121212` | Фон экрана |
| `surface` | `#1a1a1a` | Строки списка, поле поиска, карточки |
| `surface-strong` | `#242424` | Нажатая строка, выбранный день |
| `border` | `#898989` | Тонкая обводка |
| `text` | `#ffffff` | Основной текст |
| `text-muted` | `#898989` | Вторичный текст |
| `text-faint` | `#3a3a3a` | Плейсхолдеры (SEARCH, Add Exercises) |
| `accent` | `#ff3300` | Кнопки нижнего меню |
| `accent-soft` | `#ff4000` | Заголовок Fitness Tracker |
| `weekend` | `#e03a3a` | SAT/SUN в ленте недели |
| `flame-on` | `#ff000b` | Огонёк: тренировка была |
| `flame-off` | `#333333` | Огонёк: тренировки не было |

## Шрифт

Моноширинный, похож на **Source Code Pro**. Точное имя шрифта стоит проверить в Figma (выделить текст, справа панель Text). Если он другой, меняется одна строка `--font-mono` в `theme.css`.

## Компоненты (будут в коде на этапах 3–4)

| Компонент | Что делает |
| --- | --- |
| `WeekStrip` | Лента недели: день, дата, огонёк. Тап по дню показывает его упражнения |
| `ListRow` | Строка с обводкой: группа мышц или упражнение, справа может быть Play |
| `SearchField` | Поиск по списку |
| `BottomNav` | Три круглые кнопки: История, Добавить, Настройки. На «Добавить» бейдж со счётчиком |
| `SetSheet` | Выезжающая снизу карточка: вес, подходы, повторы |
| `AvatarCard` | Карточка выбора аватара |
| `FlyToHome` | Анимация: выбранное упражнение улетает к кнопке на главной |

## Поведение

- Выбор упражнений: тап по упражнению → копия улетает к кнопке главной, на кнопке растёт счётчик, экран не меняется.
- Тап по упражнению на главной → снизу выезжает карточка подходов.
- После сохранения подхода огонёк сегодняшнего дня загорается с «пружинкой».
- Все анимации отключаются, если в системе включено «уменьшить движение».

## Временное для MVP

Иконки обведены из PNG, черепа и аватары взяты как есть. Перед публикацией приложения их нужно заменить своими (у картинок из интернета может быть чужая лицензия).
