# Словарь

Термины простыми словами. Новые добавляем по алфавиту.

| Термин | Что значит |
| --- | --- |
| `.venv` | Виртуальное окружение: отдельная копия Python с библиотеками только этого проекта |
| 401 Unauthorized | Ответ сервера «я не знаю, кто ты»: нет токена или он истёк. Фронтенд в ответ открывает экран входа |
| Action (Blender) | «Клип» анимации в Blender: набор ключей для рига. Одно упражнение = один Action с именем id упражнения |
| ADR | Architecture Decision Record: короткая запись «что решили и почему». Лежат в `docs/decisions/` |
| API | Набор адресов на сервере, через которые фронтенд получает и отправляет данные |
| Argon2 | Способ превратить пароль в хеш так, чтобы подбор был очень медленным. Сейчас считается самым надёжным |
| Bearer-токен | «Предъявительский» токен: кто его показал в заголовке `Authorization: Bearer ...`, того сервер и пускает |
| Biome | Линтер и форматтер для TypeScript и CSS, аналог Ruff |
| CI (GitHub Actions) | Автоматические проверки (линтер, тесты), которые GitHub запускает на каждый PR |
| Client ID | «Имя» нашего приложения в Google. По нему Google понимает, какое приложение просит вход. Не секрет |
| CORS | Правило браузера: страница с одного адреса не может обращаться к API на другом, пока API это явно не разрешит |
| CRF | Число «качества» при сжатии видео: больше число — меньше файл и хуже картинка |
| Drag-to-scroll | Прокрутка перетаскиванием: зажал мышь на списке и тянешь, список едет за курсором, как пальцем на телефоне |
| e1RM | Расчётный максимум на 1 раз: сколько ты поднял бы однократно. Считаем по формуле Эпли: вес × (1 + повторы / 30) |
| Fake User (щит) | Кнопка-щит рядом с именем Action в Blender. Без неё неиспользуемый Action удаляется при сохранении файла |
| ffmpeg | Программа для видео: склеивает кадры в ролик и сжимает в MP4 (H.264) или WebM (VP9) |
| Google Identity Services (GIS) | Скрипт Google с кнопкой «Войти через Google» и окошком выбора аккаунта |
| HTTPS | Защищённая версия HTTP: данные шифруются. Браузер даёт микрофон и камеру только по HTTPS (или на localhost) |
| ID token | Подписанная Google строка с почтой и именем, которую отдаёт кнопка Google. Наш сервер проверяет подпись |
| JWT | JSON Web Token: строка с данными (id пользователя, срок годности) и подписью сервера. Подделать без секрета нельзя |
| layoutId | Метка в Motion «это тот же предмет»: если он пропал в одном месте и появился в другом, Motion плавно его перенесёт |
| localStorage | Маленькое хранилище внутри браузера. Данные живут только в этом браузере на этом устройстве |
| NLA | Дорожки Blender, на которых можно смешивать несколько Action. На время рендера демо скрипт их выключает |
| OAuth2 | Стандарт входа и выдачи токенов. Мы используем его простой вариант по логину и паролю (Password flow) |
| OpenAPI | Описание всех адресов API в формате JSON. FastAPI делает его сам, по нему строится `/docs` и клиент фронтенда |
| ORM | Библиотека, которая позволяет работать с таблицами базы как с классами Python |
| PATH | Список папок, где Windows ищет программы, когда ты пишешь команду в терминале |
| pathLength | Свойство SVG-линии в Motion: от 0 до 1, какая часть линии нарисована. Анимируем 0 → 1, и линия «прорисовывается» |
| Pull Request (PR) | Предложение влить ветку в `main`, с просмотром всех изменений и комментариями |
| PWA | Сайт, который можно установить на телефон как приложение |
| React | Библиотека для интерфейсов: экран собирается из компонентов |
| ResizeObserver | Встроенный в браузер наблюдатель, который сообщает, что элемент поменял размер |
| Seed | Скрипт, который заполняет базу стартовыми данными |
| SVG | Векторная картинка из формул, а не пикселей: чёткая при любом размере, цвет меняется через CSS |
| TanStack Query | Библиотека, которая загружает данные с сервера и кэширует их |
| TanStack Router | Библиотека, которая показывает нужный экран по адресу в браузере |
| TypeScript | JavaScript с типами: ошибки видны до запуска |
| Vite | Сервер разработки и сборщик фронтенда |
| Vitest | Тесты для TypeScript на базе Vite, аналог pytest |
| Web Speech API | Встроенное в браузер распознавание речи: звук в текст |
| WebP | Формат картинок, обычно в 3–5 раз легче PNG и JPG при том же качестве |
| XP | Очки опыта. Даются за тренировки и копятся в уровень |
| Zustand | Простое хранилище состояния приложения для React |
| Аутентификация | Проверка «кто ты»: вход по почте и паролю |
| Бэкенд | Серверная часть: хранит данные, считает опыт, отдаёт API |
| Ветка (branch) | Параллельная линия истории в git, чтобы менять код, не ломая `main` |
| Генерация клиента | Код запросов к API пишет программа по схеме OpenAPI, а не человек |
| Гостевой аккаунт | Аккаунт без почты и пароля: вошёл «без регистрации». Живёт, пока в браузере есть его токен. Можно превратить в обычный, указав почту |
| Дизайн-токен | Именованное значение дизайна (цвет, отступ, шрифт). В коде пишем имя `accent`, а не `#ff3300` |
| Жест pan | Свайп: палец или мышь зажали и потянули. По тому, куда и на сколько потянули, приложение решает, что сделать |
| Инвалидация кэша | Пометка «данные устарели, загрузи заново» |
| Календарная сетка | Месяц, разложенный по неделям: 7 колонок с понедельника по воскресенье |
| Коммит | Сохранённый снимок изменений с описанием |
| Компонент | Функция React, которая возвращает кусок интерфейса: кнопку, строку списка, экран |
| Кэш | Сохранённый ответ, который можно показать сразу, не спрашивая сервер снова |
| Лучший вес | Самый тяжёлый подход упражнения за тренировку. Не учитывает повторы, поэтому на графике силы его заменил e1RM |
| Миграция | Скрипт, который меняет структуру базы данных (добавляет таблицу, поле) |
| Миграция данных | Миграция, которая переносит старые записи в новую структуру таблиц |
| Мутация | Запрос, который меняет данные на сервере (добавить, исправить, удалить) |
| Объём тренировки | Сумма «вес × повторы» по всем подходам упражнения за день. Растёт и от веса, и от числа повторов |
| Подход | Одно выполнение упражнения подряд: например, 60 кг × 10 повторов |
| Прокси | Посредник: принимает запрос и пересылает его дальше, например Vite → бэкенд |
| Рекорд (PR, personal record) | Личный рекорд: самый сильный подход в упражнении за всё время. День, где он сделан, называется рекордной тренировкой. В истории отмечен оранжевым кубком |
| Серия (стрик) | Сколько недель подряд выполнена цель. Была на этапе 5, пока убрана (ADR 0009) |
| Сертификат | Файл, которым сайт доказывает браузеру, кто он, для HTTPS. Самоподписанный сделан нами, поэтому браузер о нём предупреждает |
| Тест | Маленькая функция, которая вызывает код и проверяет, что результат правильный |
| Уровень | Ступень, которую открывает накопленный XP. На новом уровне меняется аватар |
| Фоновый режим Blender | Запуск `blender --background`: без окна, только выполнить скрипт (например, отрендерить все демо) и закрыться |
| Фронтенд | То, что видит пользователь: экраны, кнопки, анимации |
| Хеш пароля | «Отпечаток» пароля: из пароля его посчитать легко, обратно пароль не получить. В базе храним только его |
| Хук | Функция React, имя начинается с `use` (`useQuery`, `useState`). Даёт компоненту данные или состояние |
| Эндпоинт | Один адрес API вместе с методом, например `GET /api/muscle-groups` |
