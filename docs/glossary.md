# Словарь

Термины простыми словами. Новые добавляем по алфавиту.

| Термин | Что значит |
| --- | --- |
| ADR | Architecture Decision Record: короткая запись «что решили и почему». Лежат в `docs/decisions/` |
| API | Набор адресов на сервере, через которые фронтенд получает и отправляет данные |
| Biome | Линтер и форматтер для TypeScript и CSS, аналог Ruff |
| CI (GitHub Actions) | Автоматические проверки (линтер, тесты), которые GitHub запускает на каждый PR |
| CORS | Правило браузера: страница с одного адреса не может обращаться к API на другом, пока API это явно не разрешит |
| localStorage | Маленькое хранилище внутри браузера. Данные живут только в этом браузере на этом устройстве |
| OpenAPI | Описание всех адресов API в формате JSON. FastAPI делает его сам, по нему строится `/docs` и клиент фронтенда |
| ORM | Библиотека, которая позволяет работать с таблицами базы как с классами Python |
| PATH | Список папок, где Windows ищет программы, когда ты пишешь команду в терминале |
| Pull Request (PR) | Предложение влить ветку в `main`, с просмотром всех изменений и комментариями |
| PWA | Сайт, который можно установить на телефон как приложение |
| React | Библиотека для интерфейсов: экран собирается из компонентов |
| Seed | Скрипт, который заполняет базу стартовыми данными |
| SVG | Векторная картинка из формул, а не пикселей: чёткая при любом размере, цвет меняется через CSS |
| TanStack Query | Библиотека, которая загружает данные с сервера и кэширует их |
| TanStack Router | Библиотека, которая показывает нужный экран по адресу в браузере |
| TypeScript | JavaScript с типами: ошибки видны до запуска |
| `.venv` | Виртуальное окружение: отдельная копия Python с библиотеками только этого проекта |
| Vite | Сервер разработки и сборщик фронтенда |
| WebP | Формат картинок, обычно в 3–5 раз легче PNG и JPG при том же качестве |
| Zustand | Простое хранилище состояния приложения для React |
| Бэкенд | Серверная часть: хранит данные, считает стрики, отдаёт API |
| Ветка (branch) | Параллельная линия истории в git, чтобы менять код, не ломая `main` |
| Генерация клиента | Код запросов к API пишет программа по схеме OpenAPI, а не человек |
| Дизайн-токен | Именованное значение дизайна (цвет, отступ, шрифт). В коде пишем имя `accent`, а не `#ff3300` |
| Инвалидация кэша | Пометка «данные устарели, загрузи заново» |
| Коммит | Сохранённый снимок изменений с описанием |
| Компонент | Функция React, которая возвращает кусок интерфейса: кнопку, строку списка, экран |
| Кэш | Сохранённый ответ, который можно показать сразу, не спрашивая сервер снова |
| Миграция | Скрипт, который меняет структуру базы данных (добавляет таблицу, поле) |
| Миграция данных | Миграция, которая переносит старые записи в новую структуру таблиц |
| Мутация | Запрос, который меняет данные на сервере (добавить, исправить, удалить) |
| Подход | Одно выполнение упражнения подряд: например, 60 кг × 10 повторов |
| Прокси | Посредник: принимает запрос и пересылает его дальше, например Vite → бэкенд |
| Тест | Маленькая функция, которая вызывает код и проверяет, что результат правильный |
| Фронтенд | То, что видит пользователь: экраны, кнопки, анимации |
| Хук | Функция React, имя начинается с `use` (`useQuery`, `useState`). Даёт компоненту данные или состояние |
| Эндпоинт | Один адрес API вместе с методом, например `GET /api/muscle-groups` |
